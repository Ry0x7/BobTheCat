# Credits

Bob is inspired by the creator's ginger cat. The private reference photograph is not included in the public source package.

The base pixel sprites and icon were created for this project with AI assistance. The ten added desktop action strips and six yarn frames were generated using the same reference-based artwork workflow as the original pet. Connected poses were extracted, registered with a shared scale per action, assembled, and chroma edges cleaned once. Frames are embedded at 192x208; yarn frames are 48x48. The laser target is a small geometric point. Rendering, behavior, and sound playback all run locally; the app makes no AI or network calls.

The four recorded meows are by Joseph SARDIN, licensed CC0; see AUDIO_CREDITS.md. The retro chirp is generated by the project's make_sounds.py script.
